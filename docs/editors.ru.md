# Поддержка редакторов

[English version](editors.md) · [Shell-канал](shell-channel.ru.md)

Hammer-MCP узнаёт редактор по хешу его exe/DLL и ищет его в [реестре сборок](../src/registry/hammers.json)
(183 сборки). Что он умеет дальше, зависит от редактора:

- **Правки через канал**: создание, изменение и удаление сущностей через [shell-канал](shell-channel.ru.md) Hammer.
- **Команды меню**: Save, Undo, Redo, Run Map, Check for Problems как сообщения `WM_COMMAND` главному окну.
- **Адаптер**: необязательная DLL, которая загружается в Hammer по кнопке *Connect adapter* (никогда в игру, в Source 2
  или в неизвестную сборку). Добавляет меню *MCP* (пауза, ожидающие правки, чат) и читает живое выделение и 3D-камеру.
- **Выделение / Камера**: что выделено прямо сейчас и куда смотрит 3D-вид (нужны адаптер и раскладка памяти для
  конкретной сборки).
- **Файлы карты**: чтение сохранённой карты, автосохранений Hammer, конфигов игры, FGD и логов компиляции. Работает для
  всех редакторов ниже.

## Заметки по редакторам

- **Hammer++** получил shell-канал только в сборке 8867 (2024-07-02). Окно называется так же, как в стоковом Hammer.
- У **стокового Hammer** и всех его форков (Hammer++, Slammin', Black Mesa, Strata, …) одинаковые id ключевых пунктов
  меню, поэтому команды меню одинаково работают на 152 сборках Source 1.
- У **Strata Hammer** интерфейс на Qt и нет shell-канала, адаптер в него никогда не загружается. Hammer-MCP читает его
  карты, конфиги и последовательности Run Map.
- В **редакторах GoldSrc** shell-канала нет вообще, он появился вместе с Hammer 4.x для Source. Hammer-MCP читает карты
  `.rmf` / `.map`, списки WAD и логи компиляции ZHLT / VHLT.
- **J.A.C.K.** и Jackhammer — отдельные редакторы (не код Valve); Hammer-MCP читает их конфиги игр, карты и настройки
  компиляции.
